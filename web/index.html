Inspect SQLite without leaving your flow.

SQLite Viewer is a terminal database browser for people who live in the shell. Open a .db file, walk the schema, page through rows, and read your data without spinning up a GUI — all with Vim-style keys and a Gruvbox palette that does not fight your eyes.

    What it does

    Small surface area, sharp edges filed off.

    01

    Native SQLite integration

    Reads .db files directly through a native binding. No server, no import step, no schema copy — point it at a file and it opens.

    02

    Gruvbox interface

    Warm cream text on charcoal, with orange as the only accent. Tuned for long sessions in a dim room.

    03

    Dual-pane navigation

    Tables on the left, rows on the right. Tab moves focus between panes so your hands never leave the home row.

    04

    Pagination & row limits

    Page through large tables with LIMIT/OFFSET and cycle between 10, 25, and 50 rows per page with a single key.

    05

    Vim & keyboard controls

    jk to move, hl to page, Enter to commit, q to leave. Mouse support is optional, never required.

    06

    Responsive layout

    The panes reflow for narrow terminals and split windows; wide screens keep the dense, two-column view.

    04

    Installation & usage

    Requires Node.js 18+ and pnpm.

    setup 
    $ git clone https://github.com/dnyaneshwar411/cli-sqlite-client
$ cd sqlite-viewer/cli
$ pnpm install
    usage 
    # open a database by positional path
$ pnpm run exe -- path/to/database.db

# or pass it explicitly with --file
$ pnpm run exe -- -f path/to/database.db
    --file, -f <path> Path to the SQLite database file to open.
    --help, -h Print usage information and exit.
    05

    Codebase

    Five files do the heavy lifting.

    └─ src/index.ts CLI entrypoint — parses argv, resolves the database path, mounts the Ink app.
    └─ src/repl.tsx Ink render loop and global key handler; maps keystrokes to app actions.
    └─ src/components/app.tsx Root component — owns selected table, page, focus zone, and row limits.
    └─ src/components/ui/gruvbox.tsx Palette constants and shared primitives: bordered boxes, badges, key hints.
    └─ src/types/index.ts Shared types for tables, columns, rows, and pagination state.
